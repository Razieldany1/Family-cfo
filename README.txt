FAMILY CFO - PWA v1.0

INSTALLAZIONE
1. Caricare TUTTI i file della cartella su un hosting statico HTTPS (ad esempio GitHub Pages o Netlify).
2. Aprire l'indirizzo HTTPS con Chrome per Android.
3. Menu Chrome (tre puntini) > Installa app / Aggiungi a schermata Home.
4. Aprire l'app e verificare i saldi iniziali; le date di assicurazione sono indicative.
5. Registrare ogni spesa, entrata o trasferimento nel pannello Movimenti.
6. Esportare regolarmente un backup JSON dalla scheda Dati.

NOTE IMPORTANTI
- Non basta aprire index.html da una cartella locale per installare una PWA.
- L'app usa IndexedDB locale e un service worker per l'uso offline dopo la prima visita online.
- Non include sincronizzazione cloud, autenticazione, notifiche push o importazione automatica del precedente Excel.
- Un trasferimento tra fondi NON è una spesa. Le scadenze non generano movimenti automaticamente.
- I saldi iniziali sono quelli comunicati in chat; saldi dei figli da verificare.
- I dati sono privati sul dispositivo, ma non cifrati con password. Proteggere il telefono e i backup.
