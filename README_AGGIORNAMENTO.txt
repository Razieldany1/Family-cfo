FAMILY CFO v1.2 — RESTYLING GRAFICO

1. Esporta prima un backup JSON dall'app installata.
2. Carica sul repository GitHub i file style.css, sw.js, index.html e manifest.webmanifest, sostituendo quelli esistenti.
3. Non modificare app.js e non cancellare i dati del browser.
4. Attendi il completamento del deploy GitHub Pages.
5. Chiudi e riapri la PWA. Se lo stile non si aggiorna subito, attendi l'attivazione del nuovo service worker e riapri.
6. Verifica i saldi, i movimenti, i fondi e l'operatività offline.

L'aggiornamento cambia soltanto presentazione e cache. Non esegue migrazioni del database.
