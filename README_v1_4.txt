FAMILY CFO v1.4 - Categorie personalizzate

Novità:
- In Dati > Gestione categorie, creazione categorie di spesa e di entrata.
- Categorie nuove selezionabili nel Movimento rapido e nel modulo dettagliato.
- Rinomina: aggiorna movimenti storici, preferiti e budget associato.
- Eliminazione bloccata se la categoria è usata da movimenti o preferiti.
- Le categorie di spesa nuove partono con budget mensile 0 €, modificabile in Dati.
- Salvataggio nel medesimo IndexedDB 'family-cfo', senza reset dei dati esistenti.

PRIMA DELL'AGGIORNAMENTO: esportare il backup JSON dalla v1.3.
Sostituire i file su GitHub Pages, senza cancellare i dati del browser o disinstallare la PWA.

COLLAUDO: creare una categoria di prova, verificarla in Movimento rapido,
rinominarla, eliminarla (senza movimenti reali) e verificare saldi e storico.
